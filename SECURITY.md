# Security and private data

audioseyX is an experimental local application. It binds to loopback, uses a per-session write token and checks request origin. It is not designed to be exposed as a public web service.

Do not post account credentials, API tokens, private receiver backups, identifying file paths or personal measurement archives in public issues. A minimal synthetic reproduction is preferred.

For a sensitive vulnerability, use GitHub's private vulnerability-reporting feature if it is enabled for the repository. Otherwise contact the repository owner privately before sharing exploit details. Do not assume that the project's MIT license grants rights to third-party compatibility resources.

Only the current public prerelease is maintained. There is no promised response-time or long-term-support guarantee. Physical receiver support remains experimental.
